# The parity board (docs/parity/)

`BOARD.md` is generated by `python3 -I tools/scoreboard/board.py` and never
hand-edited. It renders one row per panel from the committed control files
(`controls/*.control.jsonl`), the classification manifest
(`controls/classified.jsonl`), and `panels/LABELS.json`.

Reading a row:

- **Items / Test asserts / Agree / Classified / Unexplained.** *Test asserts*
  is the number that measures something today: EKOS's own function, run by
  `control-dump` on the transcribed input, reproduced N of M of the Rust
  test's assertions (`--expected`, from the run recorded in
  `controls/MANIFEST.json`). *Agree* is a control-vs-candidate run through
  `score.py`'s diff code; **no VerEKOS candidate exists yet**, so today it is
  the control against itself (exploration 03 §3.5-1), which proves only that
  the diff code runs. Agree + classified + unexplained = items (§3.1). The law
  is zero *unexplained*; a classified difference is counted and shown, not
  hidden, and a `verekos_defect` classification stays red (`score.py` exits
  1) until fixed.
- **Assurance** — one of the five labels below, from `panels/LABELS.json`.
  The label describes the kernel's *claim*, never the panel result: a panel
  can be 100/100 and still `design target`.
- **Scope / Does NOT measure** — both mandatory; the generator refuses to
  render a row with either cell empty.

## The five assurance labels

The definitions live once, in `panels/LABELS.json` (`assurance_labels`), and
`board.py` prints them at the foot of `BOARD.md`. Exploration 03 §3.6 took the
five names from the hyperdreggmedia audit, which is not in this repository;
the wording is ours, rewritten on 2026-10-19 for Lean when the Isabelle layer
was dropped. A theorem about a `world/` definition does not move a row past
`design target` until that same definition answers the panel's items.

## Files

- `docs/parity/BOARD.md` — the board (generated).
- `panels/LABELS.json` — assurance label + the two mandatory prose cells per
  panel; placeholder rows for kernels without a control yet.
- `controls/classified.jsonl` — append-only manifest of explained
  differences, one line per difference, keyed by the sha256 of the canonical
  (panel, item, control, candidate) tuple with class `ekos_defect` /
  `verekos_defect` / `non_goal` and a one-line reason. Change the control,
  the candidate or the item and the hash changes: the difference counts as
  unexplained again until re-classified.
- `tools/scoreboard/score.py` — the scorer; `tools/scoreboard/board.py` —
  the renderer.
